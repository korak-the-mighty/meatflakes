# What Henrik does next

**Order matters. Start here.** The current goal is to learn whether a desirable product has a credible technical path. Nothing in this list authorizes selling or ambient-storing an unvalidated meat sample.

## 1. Make Prototype 001

- [ ] Read [the one-batch chicken protocol](02_PRODUCT_R%26D/PROTOTYPE_001.md). Buy one chicken batch and choose five simple dishes: rice, baked potato, instant ramen, scrambled eggs and pasta.
- [ ] Make four small labeled texture trials **A crispy, B flaky, C softening, D fat/flavor**. Use safe handling for prompt sensory testing; no home shelf-life experiment.
- [ ] Photograph and log inputs, process observations, starting/finished weights and tasting scores. Compare dry and after 1, 3 and 5 minutes on hot food.
- [ ] Write one sentence: **Which variant would I actually reach for again, on which dish, and why?** If the answer is none, revise the format before spending on scale-up.

## 2. Start expert outreach

- [ ] Read [the product brief](08_EXPERTS/EXPERT_BRIEF.md); send a concise request for an introductory feasibility call to [IASP Berlin, DIL and FutureFoodCo](08_EXPERTS/CONTACTS.md). Confirm the appropriate team and current scope before treating any as a partner.
- [ ] Ask for likely safe process routes, biggest failure modes, what an initial paid feasibility study would include, available pilot/analysis capabilities, indicative timing and a written scope/price. **Book conversations first; commission no full program from an untested concept.**
- [ ] Capture each reply, contact date, questions and next step in a private working log. Put only nonconfidential conclusions in this public repository.

## 3. Start prior-art research

- [ ] Work through [the search notebook](04_IP_PATENT/PRIOR_ART.md). Search patents and products for meat flakes, bacon toppings, floss/rousong, dried or rehydratable meat pieces, and packaging/process claims. Log exact publication, date, jurisdiction and overlap; do not infer clearance from a keyword hit.
- [ ] Record what this public repository already discloses. If experts identify a potentially novel specific process or formulation, ask patent counsel about timing and disclosure before posting those details publicly.

## Then follow the gates

4. [ ] **Eating experience:** at least one chicken format is enjoyable, visibly meat and useful in a dish. Repeat with a small controlled iteration if needed.
5. [ ] **Technical feasibility:** a qualified food technologist identifies a credible process and test program for a safe ambient product; document key uncertainties and cost.
6. [ ] **IP reality:** counsel or a competent specialist reviews the exact relevant claims and publication history before any patent or freedom-to-operate statement.
7. [ ] **Professional pilot:** make only a few focused candidates (roast chicken, beef, guanciale/carbonara if feasible) under an appropriate food safety system; define release criteria before testing.
8. [ ] **Safety and shelf life:** qualified experts validate process, microbiology, packaging, quality and an actual shelf life. **12–24+ months unopened remains a target until supported by data.**
9. [ ] **Real household behavior:** with a professionally safe product, run [the 30–50 household, 7–14 day test](07_TESTING/CONSUMER_TEST.md). Count repeat use and pack completion, not compliments.
10. [ ] **Economics:** replace every blank in [unit economics](05_BUSINESS/UNIT_ECONOMICS.md) with measured yield, quotes and channel terms. Make the [go/no-go decision](05_BUSINESS/GO_NO_GO.md).

**The next update to this repository should be evidence:** a dated Prototype 001 summary or a verified expert response, clearly separated from hypotheses.
